# SnapPDF Lite PWA
獨立製作的 PDF 工具 PWA 示範，非 SnapPDF 官方產品。

## 部署
把整個資料夾上傳至支援 HTTPS 的靜態網站平台（如 Netlify Drop、Cloudflare Pages 或 GitHub Pages）。請不要用 `file://` 直接開啟，PWA 與 ES Modules 需要網頁伺服器。iPhone 用 Safari 開啟網址 → 分享 → 加入主畫面。

## A4 自動掃描（修正版）
- 點「Open Camera」啟動應用程式內即時相機（首次需允許相機權限）。
- 將完整白色 A4 紙放在**較深色且有對比的背景**上，保持四邊完整入鏡。偵測到紙張會出現青綠色框；連續穩定約 1 秒會自動拍照、透視拉正並產生 A4 比例圖片。
- 將紙移出畫面再放入可拍下一張；亦可按「再次掃描」重新啟用自動偵測，或按白色圓形鍵手動拍照。
- 點「完成並製作 PDF」可把已拍頁面合成一份 PDF，儲存在本機 My PDFs。
- 彩色印刷品若無法辨識完整紙張輪廓，約 2 秒後改為黃色虛線框備援模式：把紙張對齊框內，保持手機穩定約 1.5 秒自動拍攝。備援模式完成一張後需按「再次掃描」才會拍下一張，避免重複拍攝。備援模式使用固定框裁切，不保證與紙張邊緣完全吻合。必要時仍可按中央白色快門。
- 本修正尚未在實體 iPhone 上實測；請先用測試文件確認裁切結果。
- 行動瀏覽器必須透過 HTTPS 部署並核准相機權限；不能從檔案管理器直接開啟 HTML 使用即時相機。

## 功能
- 圖片、相機轉 PDF
- 開啟、預覽、下載 PDF
- PDF 合併
- 壓縮（將頁面光柵化，可能失去可選取文字，且不保證檔案必定更小）
- 輸入已知開啟密碼解鎖（光柵化輸出）
- 簽名、英數字浮水印
- 本機 IndexedDB 保存文件，離線啟動（首次連線載入外部 JS 元件）

## 限制
- Protect PDF 尚未實作（不提供假加密）。
- 不支援中文浮水印（預設 PDF 標準英文字體不含中文字）。
- 受密碼保護 PDF 的原生修改與合併可能失敗。
- PDF 文件可能很大，iOS 記憶體有限；清除 Safari 網站資料會使本機文件消失。請下載備份。
- 本專案未含自動化安全稽核或跨機型相容性測試。
